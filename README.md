## 8条核心经验：问题、修正与检查放在一起

以下结合实践反馈与需要预防的问题。每条都说明为什么这样做、出了问题怎么改，以及如何检查结果；检查标准不代表已经验证通过。

### 1. 先定音频，再安排镜头时长

- **问题：** 段落秒数不准、换人切入错位；镜头切得太碎，反复生成费劲。
- **修正：** 用实际采用的音频确定歌词起止、长音和换人时间。按完整乐句组织约12秒制作单元，内部切换景别，不硬凑整数时长；根据工具能力再拆分。音频更换后，重新检查受影响镜头。
- **检查：** 时间线能连续拼接，歌词和尾音没有被意外截断，切入点对应正确人物与乐句。

### 2. 修音同时处理音高、音量和衔接

- **问题：** 尾音漂移、气息听感不稳、声音忽大忽小，替换片段接入生硬。
- **修正：** 按参考旋律修正音高，分别平顺音量起伏与尾音衰减；替换时匹配前后调性、音量、音色、节奏和空间感。保留自然颤音、滑音、咬字与情绪。发声技巧问题无法自然修复时，标记重录建议。
- **检查：** 连续播放替换点前后，声音不突变，字音与尾音完整，修后仍保留本人特点。

### 3. 合唱逐人明确，首帧就要各自持麦

- **问题：** 只有主角拿话筒，其他人被生成成陪同表演或旁观者。
- **修正：** 明确姓名、人数、同等数量的独立话筒、持麦手和共同歌词。首帧每个人都举麦；每个多人镜头都要求所有入画人物持续演唱。特写切换不代表轮流独唱。
- **检查：** 逐个镜头核对人数、话筒与唱歌状态；走步、对视时也没有无故放下话筒或停止演唱。

### 4. 口型跟真实音频，尾奏自然收口

- **问题：** 嘴型与歌词不符、切镜后重复起唱，或人声结束后仍然动嘴。
- **修正：** 提供本段原速音频和完整歌词，用音频驱动或后期对口型。连读、拖音和换气按实际演唱处理，不按字数平均分秒；切镜继续当前字音。实际人声结束后才收口，尾奏不新增唱词。
- **检查：** 对照音频检查起字、长音、停顿和结尾。未核验的时间标为参考，不能把补上歌词当成已经对齐。

### 5. 互动有发起、回应和共同走位

- **问题：** 人物只站着叹气，伸手没有回应；加入动作后又忘记唱歌。
- **修正：** 写清“谁邀请—谁回应—如何一起移动—最后站在哪里”。每个乐句安排一个主要互动，通常移动一至两步；空闲手互动，持麦手稳定，动作期间继续唱词。
- **检查：** 能看懂人物之间的关系与动作结果；回应自然，走位清楚，唱词没有被动作打断。

### 6. 景别配合动作，切镜保持连续

- **问题：** 全程大特写看不到走位，或一直远景看不清表情；切镜后动作与位置对不上。
- **修正：** 半近景交代走位，双人近景拍回应，面部特写拍关键唱词，再回到多人画面。人物前行时镜头后退或跟移，切镜保留当前动作进度和舞台空间关系。
- **检查：** 互动动作看得清，特写中的嘴唇与眉眼可辨认，前后镜头没有人物瞬移或动作重新开始。

### 7. 背景灯光变化，脸部照明稳定

- **问题：** 舞台灯光始终不动、配色偏离参考，或变化的灯光影响人脸与口型辨认。
- **修正：** 按舞台参考固定配色，明确光束移动方向、重拍提亮时机与收尾状态。背景光束运动，人物面部保持自然中性白柔光。
- **检查：** 背景确实有运动和明暗变化，配色与舞台一致，脸部不过曝，肤色和嘴唇始终清楚。

### 8. 首帧先解决人物、肢体和空间问题

- **问题：** 人物拥挤遮挡、手臂重叠、左右失衡，或生成过程中妆造与人数变化。
- **修正：** 先检查静态画面的身份、服装、人数、话筒、手部和走位空间。充分利用舞台，减少复杂交叉与多人同时接触。重点人物过多时，先确认群像图再拆组拍摄；身份不变，位置按设计移动。
- **检查：** 首帧和关键帧中的人数正确、脸部可见、肢体自然，人物有空间完成走位，前后妆造一致。

## 每次开始前只填这6项

- **音频：** 当前采用哪一个文件，本段的入点、出点和完整歌词。
- **人物：** 谁出镜，共几人，几支话筒，参考图分别对应谁。
- **画面：** 用哪张舞台或首帧图，人物起始位置是什么。
- **动作：** 谁发起互动，谁回应，最终站到哪里。
- **摄影：** 哪句用半近景，哪句切特写，镜头如何跟随。
- **衔接：** 开头承接什么，结尾还有没有人声，末帧保留什么状态。

## 后续怎么更新

新作品发现一条确实有用的经验，就补进本页；需要复用的表述，补进提示词合集。
新条目沿用同一结构：**核心经验 → 出现的问题 → 修正方法 → 检查标准**。实际使用后，再补一句验证结果。
效果尚未验证就写“待验证”，不要把尝试当成已经成功的方法。
