# 《零号舞台》制作避坑速查

索引：**写作先过可拍性检查**；**每次生成检查**＝输入规格 → 首尾帧 → 人物与道具 → 台词与动作；**一次性处理**＝命名、素材整理、名牌方案、舞台风格。按影响从大到小排列；“每次检查”表示容易复发，不代表每项都已发生多次。

## 写作硬性要求：可拍、可听、可验证

**问题类型：视听叙事与可拍性。每次写分镜前先读，交付前逐条检查。**小说可以直接叙述心理；剧本落实人物的行动、对白与事件结果；分镜进一步安排观众何时看见、听见这些信息，以及怎样拍出来。

1. **心理转成证据。**“她意识到被困”须改成寻找出口、试路、受阻或询问等可见事件；情绪落实到具体表情、身体和声音。不擅自增加内心旁白，也不让人物把所有心事说出来。动机留在角色设计文档。
2. **互动必须有回应。**谁做／说什么，对方看见／听见后怎样行动，结果改变什么。不能只给主角台词，其他人排队点头；也不为增加动作而堆无目的走位。
3. **信息必须有镜头依据。**先让观众看见线索、距离或阻碍，再拍反应与选择；不能靠一句“她懂了”或单个皱眉承载复杂推理。每段突出一个主要事件，摄影机有明确观察对象。
4. **画面、声音和时长一起设计。**后续生成片段默认15秒左右，通常12—16秒，一段只承担一个主要事件或一轮完整互动，减少重做范围。规则分配给核心口播与清楚屏显，给问答、动作、喘息留时间；超量就精简或自然拆段，不加速台词。完整动作不拆断，结尾状态可接下镜。
5. **精简生成正文。**参考绑定、站位和音色各写一次；分段只写机位、动作、对白、结果。优先正面描述，删除重复禁令与解释；保留首帧、人数、关键支点和落点。制作备注、检查表放在可复制正文之外。
6. **逐句验收：镜头拍到什么？声音听到什么？这段推进什么？**没有答案就改写或删去；再核对支点、动作连续性、台词时间和参考素材。文字核对不等于成片验证。

## 一、高频问题：每次生成都检查

| 优先级／影响 | 问题类型 | 问题 | 可复用做法 |
| --- | --- | --- | --- |
| **1 · 无法提交** | 输入规格 | 图片尺寸不合格 | 上传前读实际宽高，尾帧也检查。本次接口报错要求高度 **300—6000 px**；宽度、比例等另按接口要求核对。简单文字样式直接描述，不上传小裁图。 |
| **2 · 无法提交或错绑素材** | 素材引用 | 图太多、名字对不上、引用未提供附件 | 总数最多10张，优先≤9张，包含首帧；图片只写完整原文件名。不写“图一图二”、本地路径、链接或未上传音频；音色用文字描述。 |
| **3 · 整段衔接失败** | 镜头连续性 | 首帧重画、重复起身、沿用旧尾帧 | 上一镜实际末帧放入Start Frame；第0帧直接沿用，按本镜时长承接0.2—0.8秒自然余动；继承完成姿态，不重演到达该姿态的动作或对白。上一镜重做，尾帧必须重新导出。片段优先在视线转向、答话或场景转移处分界；不截断完整动作，不强加转场，切镜不能代替首帧衔接。 |
| **4 · 人物或空间错乱** | 视觉一致性与空间连续性 | 重复人物、换脸、道具变形；切空席后人物跑进观众席 | 每个角色最多一具身体，通常每段≤6个形象；04新增背景同伴时按取景表跨切镜安排，单帧总数仍≤6，远处人也计数。全身格、特写格、尾帧绑定同一人，画外声音与快动作不新增身体。弦歌例外为一本体＋一傀儡、一个身份。每次切回核对台缘、所属支柱、主舞台边沿与席区边界；云台留在机械池原位，不能搬到座席地板。看向某处不等于走过去，空席反打须零人物。远景同伴绑定原平台，浅虚化仍保留身影，不因切近景而清空整片云台；全员参考只取本镜点名的背景角色。重复人物可改单张全身图测试；错误人数或站位的尾帧不能续用。 |
| **5 · 危险与行动原因看不懂** | 场景与空间设计 | 只写“惊险”，实际仍有完整护栏和落脚点；变化靠晃镜表达 | 先写位置、距离、高差、开口、支点；再写哪部分移动、朝哪边、多久完成、如何失去支撑。核对机关顺序与双脚位置，并查左右、底部及上方是否能轻易绕过危险；确保人物确实尚未到安全区、动作确有必要；镜头同时拍清人物、危险位置和可用落点；静态参考图与动态结构的差别须说明。米数必须有画面证据：断口与人身高同框、下降经过固定楼层／灯带；落地后留出旧台继续下落及最终落差。 |
| **6 · 重做成本高、信息挤或尾段空转** | 节奏与生成片段长度 | 单段太长、多组事件捆绑；对白太密或结尾发呆 | 后续新写、重写默认15秒，通常12—16秒；一个主要事件、一轮完整互动，减少多人组切换。超量先精简或在动作完成、答话结束处分段，不加速台词、不截断完整动作、不靠空拍凑时长；同步更新编号和首尾帧。 |
| **7 · 动作断续或像摆拍** | 动作设计 | 每招停住、无支点、慢镜拖长 | 写“承重→蹬地→腰肩转向→落脚缓冲→下一动作”。上一动作末态直接带出下一动作；写清左右手脚、发力来源、方向、距离与完成时间。速度用实际位移和环境反馈体现；表情随受惊、判断、发力、脱险变化，关键支点保持可见。 |
| **8 · 剧情反应不成立** | 叙事与表演 | 心理说明代替画面、人物先说结论、配角不回应 | 按“发现异常→观察确认→行动→回应”写。险情先拍清缺口、落差、倾角和失去支撑，再拍自救；只写“危险”或人物表情不够。险情要有触发、判断、解决和可见结果；让同伴用目光、手势或接应参与。 |
| **9 · 审核或声音效果不稳** | 提示词与声音 | 只写抽象刺激词、每镜配乐不衔接 | 题材限制须同步修改任务目标与失败后果，不只替换词语。当前以规律分析、协作为主；音效写声源、起止点和触发事件。持续声跨切镜与对白不断；如掌声，须响到“停一下”最后一字结束才切断，不能抬手或开口便停。不生成背景音乐，后期统一配；措辞修改不等于已通过审核。 |

**场景与动作必写：**从哪里开始 → 什么发生变化 → 人物怎样受影响 → 用哪里发力／支撑 → 多快移到哪里 → 表情与身体怎样回应 → 最后停在哪里。不能只写“突然、危险、敏捷”；必须给可拍的动作与空间证据。障碍须核对角色已展示的能力：桥断开不等于无人能跨越，锁门与任务通行条件须另外交代。快动作连贯完成，观察反应留出时间；结尾状态接下一镜。

**动作速度与幅度检查：**位移／腾空时间分别写清；起点、越过的障碍和落点同框可见。脱险用短蓄力、爆发、落地卸力，少用无目的转圈与舒展摆臂。不要把多句动作拆成逐招定姿，也别把收腿高度当成跳跃高度。接扶先按左右站位选近侧手，写清距离与接触部位，支撑手和接人手不能冲突。摄影机适度跟随，保留静物参照；增加幅度须同步扩大障碍、助跑与落地空间。需要升级险情时，扩大实际断口、落差或失去支撑的规模；只换“更惊险”措辞或放大表情无效。大动作必须拍全起跳、跨越、落地与制动。

**背景人物速查：**先定原平台，再定该机位实际能见的名单、大小和遮挡。近处清楚、远处轻虚焦，背景只做短转头或扶栏等小动作；不凭空填路人，不用全员拼图自动生成整场群像。主屏零人物镜头只裁切屏幕，不能顺带把画外同伴的云台改为空台。

**通用原则：**文案改好、文件检查通过、视频生成成功分开记录。先确认新片合格，再拿它的尾帧继续下一镜。

## 二、一次性处理：沿用当前方案

| 已处理事项 | 问题类型 | 后续直接沿用 |
| --- | --- | --- |
| 剧名与角色改名 | 命名管理 | 使用《零号舞台》及当前剧中名；不反复切回旧名。原名只用于素材溯源。 |
| 人物图片重拼 | 素材制作 | 从“剧中角色设定”选个人拼图，保留原画质；不用旧缩略图重新拼。弦歌图已含本体、傀儡及关系。 |
| 姓名裁图高度不足 | 输入规格 | 402×194旧图已停用。姓名用细白宋体、渐淡细线、中央小空心菱形、透明底，放在人物侧边留白处。无需重新放大上传。 |
| 舞台太暗、头像装饰不合适 | 美术风格 | 使用三张“原创装饰版”舞台图；明亮可爱配色，危险通过机关、落差和反应呈现。 |
| 规则与能力边界 | 世界观与规则 | 全员保留；规律分析与团队协作，失误只影响进度和评价；解谜后旧照片线索保留。每场观众70分＋任务20分＋导师10分，累计排名分档、达标解锁强化；观众评分不能代替共同通关，空席不因评分而补人。基础本领可用，不临时新增解题能力。 |

一次性处理的是具体方案；新图片的尺寸、新分镜的名称、规则及引用仍按上表检查。
